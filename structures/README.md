# structures — Métodos y estructuras de datos

Mis checklists para dominar las estructuras de datos en JavaScript/TypeScript. Un archivo por estructura, con la lista de métodos o conceptos que quiero tener controlados.

Marco `- [x]` cuando ya lo domino de verdad (sé qué devuelve, si muta, y sus casos borde), no cuando lo he leído una vez.

## Cómo lo uso

1. Elijo un archivo y voy método a método.
2. Pruebo cada uno en consola: caso normal, estructura vacía, valores raros.
3. Me pregunto siempre lo mismo: **¿muta o copia? ¿qué devuelve? ¿qué coste tiene?**
4. Solo entonces marco la casilla.

Aquí no hay nada que ejecutar: son notas.
