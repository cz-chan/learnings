# Creación de estructuras: literal vs constructor

- [ ] Array: `[]` vs `new Array()`
- [ ] Array: `new Array(3)` vs `new Array(1, 2, 3)` (el caso especial de un solo argumento numérico)
- [ ] Array esparcido (sparse array) y cómo afecta a métodos como `forEach`/`map`
- [ ] Object: `{}` vs `new Object()`
- [ ] Map / Set: no tienen forma literal, solo `new Map()` / `new Set()`
- [ ] TypeScript: anotar tipo (`let arr: number[] = []`) vs crear con genérico (`new Array<number>()`)
- [ ] Rendimiento: por qué se prefieren los literales sobre los constructores
