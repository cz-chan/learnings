# AGENTS.md — reasoning-files/

Instrucciones para cualquier agente de IA (Claude Code, Cursor, Copilot, Codex...). Mismo contenido que `CLAUDE.md`. Hereda las reglas de `../CLAUDE.md` y de la raíz.

## Qué es esta carpeta

**Archivo histórico.** Contiene el *primer intento* de cada reto de `midu-dev/`, con los errores cometidos ya identificados y comentados en el propio código. La versión buena vive un nivel más arriba, con el mismo nombre de archivo.

Existe para que el usuario pueda releer **por qué falló**, no para tener el reto resuelto dos veces.

## Reglas específicas — importantes

- **No corrijas estos archivos.** Los bugs son intencionados: son el contenido. Si detectas uno "sin arreglar", no lo toques; como mucho, dilo.
- **No los sincronices** con la versión final ni elimines duplicación entre ambas carpetas.
- No los borres ni los reorganices "por limpieza".
- Sí puedes: añadir o mejorar los comentarios que **explican** un error, si el usuario lo pide.
- Cuando el usuario pregunte por un reto, aclara de qué versión habla: el intento (aquí) o la final (`../`).

## Regla socrática

Sigue aplicando. Si el usuario pregunta "¿por qué fallaba esto?", empieza por una pregunta que le haga encontrar el caso que rompe, no por el diagnóstico.
