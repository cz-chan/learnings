# advent-js

Mis soluciones a los retos de [AdventJS](https://adventjs.dev), el calendario de adviento de programación de midudev. **JavaScript puro.**

## Formato

Un archivo por reto: `NN-challenge.js`

```js
/**
  Enunciado completo del reto...
 */

function solucion() { ... }
```
