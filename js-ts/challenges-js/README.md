# challenges-js — Retos y katas

Retos de algoritmia que resuelvo yo mismo. El objetivo no es tener el código bonito: es entrenar la cabeza.

## Contenido

| Carpeta | Qué se hace ahí |
| --- | --- |
| [`advent-js/`](advent-js/) | Retos del calendario de [AdventJS](https://adventjs.dev) (JavaScript). |
| [`midu-dev/`](midu-dev/) | Retos de [midu.dev](https://midu.dev) resueltos en TypeScript. Incluye [`reasoning-files/`](midu-dev/reasoning-files/) con mis primeros intentos y los errores documentados. |

## Formato de cada reto

Un archivo por reto, numerado `NN-nombre`:

1. Arriba, el enunciado completo en un bloque `/** ... */`.
2. Debajo, mi solución.

## Mi flujo

1. Leo el enunciado y lo resuelvo sin ayuda.
2. Si me atasco, pido **pistas** — nunca la solución (ver `CLAUDE.md`).
3. Cuando funciona, guardo la versión buena en la raíz de la carpeta.
4. Si el primer intento tenía bugs interesantes, lo conservo en `reasoning-files/` con los fallos comentados, para no repetirlos.
