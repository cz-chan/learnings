# js-ts

Todo mi material práctico de **JavaScript y TypeScript**: lo que se escribe y se ejecuta (a diferencia de [`../structures/`](../structures/), que son solo notas).

## Contenido

| Carpeta | Qué se hace ahí |
| --- | --- |
| [`challenges-js/`](challenges-js/) | Retos de algoritmia que resuelvo yo: AdventJS (JS) y midu.dev (TS). Incluye mis primeros intentos con los errores documentados. |
| [`mouredev-courses/`](mouredev-courses/) | El curso de JavaScript de MoureDev. Lecciones comentadas tema a tema (`basic/` e `intermediate/`) y sus ejercicios. |

## Diferencia entre las dos

- **`challenges-js/`** → problemas cerrados, yo pongo la solución desde cero.
- **`mouredev-courses/`** → aprendizaje guiado: primero leo/escribo la lección, luego hago los ejercicios del tema.

## Ejecutar

```bash
node mouredev-courses/basic/06-array.js
node mouredev-courses/intermediate/04-async.js
```
